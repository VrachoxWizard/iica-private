# IICA-ESG frontend

Clean Next.js recreation of [iica-esg.com](https://iica-esg.com/). Original WordPress scrape in the repo root is left untouched.

```bash
npm install
npm run dev
```

- Croatian (default): http://localhost:3000
- English: http://localhost:3000/en

Forms validate locally and show a success message. They do not submit to WordPress or third-party APIs.
